# Photos: what to find and how to add them

Free-licence sites: Unsplash, Pexels, Pixabay (keep each photo's credit).

| Collection | Search keywords |
|---|---|
| Hero (optional) | Manipur hills, Ukhrul landscape, Northeast India mountains mist, terraced hills India village |
| Education (education-*.jpg) | rural school India classroom, school bag walking village, student writing notebook, books and uniform India |
| Digital literacy (digital-*.jpg) | computer lab rural, laptop workshop community, women learning computer, typing keyboard hands, village computer training India |
| Community (community-*.jpg) | village India Northeast, community meeting India, women leaders India, Naga Tangkhul village, hands together community |
| Marathon (marathon-*.jpg) | marathon runners India, fun run crowd, runners start line, trail running hills, race finish medal |
| Events (events-*.jpg) | community gathering candle, memorial candles, workshop training session, volunteers handing supplies |

Guidance: 12-20 photos, landscape 1600px+ (a few portrait ~1200x1600), under 1 MB each, no watermarks or visible logos. Use children's faces sparingly (hands, books, backs, wide shots).

**Prototype:** put files in `mnm-foundation-core/assets/demo/photos/` named with the prefixes above, then Foundation > Demo Content > Install / refresh.
**Real site:** Media Library > upload > add a Caption and a Gallery collection to each. Optional homepage hero photo or MP4 video: Foundation > Website Settings > Homepage (a photo or video switches the hero to a full-bleed centred layout).
