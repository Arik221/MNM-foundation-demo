# Staff guide (non-technical)

Log in at `/wp-admin`. The heart-shaped **Foundation** menu has everything:

| I want to... | Go to |
|---|---|
| See a summary | Foundation > Overview |
| Add or edit a programme / project / event / article | Foundation > Programmes / Projects / Events / Articles > Add New. Fill in the **details box** under the text. Use **Save Draft** to keep it private; **Publish** to show it. |
| Post marathon news | Foundation > Marathon Updates > Add New |
| Upload photos | Foundation > Gallery Photos (Media) > Add. Open a photo, write a **Caption**, and choose a **Gallery collection**. A photo only appears in the public gallery once it has a collection. |
| Create a gallery collection | Foundation > Gallery Collections |
| See who registered | Foundation > Registrations. Search, filter by race/status, **Mark confirmed**, or **Export all to CSV**. |
| Update fundraising | Foundation > Fundraising Campaigns > open one > edit *Amount raised (manually verified)* and the verification note > Update. Only enter amounts you have checked. |
| Change phone, address, social links, homepage text, announcement bar, statistics, footer | Foundation > Website Settings (administrators) |
| Edit a page's wording | Pages > edit the page |
| Change the menu | Appearance > Menus |

Roles: **Administrator** sees everything. **Editor** accounts see content, gallery and registrations but not settings or plugins.
Anything labelled *Sample* or *Demonstration data* is placeholder content to replace.
