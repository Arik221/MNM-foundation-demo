Drop real photographs here (jpg/png/webp), then run Foundation > Demo Content > Install / refresh.
Name files with a prefix to choose the gallery collection:
  education-*.jpg   digital-*.jpg   community-*.jpg   marathon-*.jpg   events-*.jpg
Files without a known prefix are spread across collections. Use 12-20 photos, landscape 1600px+ (a few portrait).
Image credit lines: add them in the Media Library caption or the footer note in Website Settings.
